# Verificação do Git sync / GitHub

## Objetivo
Responder se o código do projeto está sendo enviado automaticamente para o GitHub após publicar.

## Passos
1. Verificar o estado atual da integração Git sync do projeto.
2. Informar se o envio automático para o GitHub está ativo ou inativo.
3. Caso esteja inativo ou desconectado, apresentar as opções para reconectar.

## Resultado esperado
- Confirmação clara se Git sync está funcionando.
- Próxima ação recomendada (reconectar ou nada a fazer).
