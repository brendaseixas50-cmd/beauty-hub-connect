# Conexão do Git sync com GitHub

## Objetivo
Ativar o envio automático do código do projeto para um repositório GitHub.

## Limitação
A conexão Git sync exige autorização OAuth direta na conta do usuário no GitHub e escolha da conta/organização/repositório. Isso não pode ser feito automaticamente pelo agente sem interação do usuário.

## Passos a executar
1. Abrir o menu Plus (+) no canto inferior esquerdo do editor Lovable.
2. Selecionar GitHub → Connect project.
3. Autorizar o app do Lovable no GitHub.
4. Escolher a conta ou organização desejada.
5. Criar o repositório (ou selecionar um existente, se disponível).
6. Confirmar que o remote do GitHub aparece no projeto.

## Resultado esperado
Após a conexão, toda alteração no código será sincronizada automaticamente com o GitHub, independentemente de publicar o site.
